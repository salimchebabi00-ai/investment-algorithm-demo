# Quantum Fractal Trading Lab

This repository contains a starter crypto trading simulator that blends:

- fractal signal scanning
- deep-learning style prediction UI
- virtual money simulation
- chart layers inspired by TradingView
- multi-timeframe signal structure
- conceptual quantum-inspired optimization layer

## What is included

- Next.js app with RTL Arabic interface
- market simulation and forecast engine
- multi-timeframe dashboard UI
- signal cards for deep learning, fractal, and quantum-inspired optimization
- live-style chart overlay with forecast path

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Notes

This is a research/demo platform for experimentation and education, not a guaranteed profit engine. The project is designed to simulate strategies and evaluate signals in a controlled environment before any real-money deployment.
